# Post-Incident Assessment Report

## Objective
This project is a report that analzyes a fictional cyber attack and provides recommendations in-line with audit frameworks like ISO/IEC 27001:2022 and SOC 2.

### Skills Learned
- Cybersecurity auditing
- Technical Reporting
- ISO/IEC 27001:2022 and SOC 2 frameworks

### Tools Used
- ISO/IEC 27001:2022
- SOC 2

### Project Overview
This report outlines a fictional attack that was performed against a fictional company. The report describes the details of how the attack was performed, and the gaps in the company that allowed the attack to advance. It also includes recommendations for the company to implement, that are in-line with the ISO/IEC 27001:2002 and SOC 2 frameworks.
